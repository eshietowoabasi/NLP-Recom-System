# NLP-RS: curriculum recommendation system

NLP-driven recommendations for the institution-specific 30% of the NUC CCMAS
Computing curriculum (Department of Computer Science, University of Uyo).

Open the app at its direct address (`https://<owner>-<space>.hf.space`), not inside
the Hugging Face page: sign-in cookies are not sent inside the embedded frame.

This Space is deployed automatically from the GitHub repository. Data is stored
inside the container and is reset whenever the Space restarts.
